A rule needs a route back to its evidence.

A harness is the workflow, checks and instructions around an agent. A lessons file can tell an agent what to do; a governance process also records why a rule exists, who approved it and when it needs another look.

Keep the candidate separate

Evidence and proposed actions are material for review. A candidate is not an instruction, and retrieval alone does not grant it authority.

Put a person at the gate

Activation requires recorded approval. The checker checks the recorded approval before an active rule can be rendered.

Revisit the rule

Recorded violations can prompt a person to sharpen, enforce or retire guidance. The program flags a pattern; it does not choose the remedy.

Learning from execution

On AppWorld, offline ACE without ground-truth labels scored 57.2 versus 42.4 for ReAct alone: a 14.8 percentage point difference averaged across four completion metrics. The base model was DeepSeek-V3.1-671B; ACE used an automatic generator, reflector and curator.

Retrieving experience

In LongMemEval-V2, AgentRunbook-C scored 74.9% versus 69.9% for Codex on the small tier, and 70.1% versus 68.7% on medium. The benchmark tests retrieved experience in specialised web environments.

Retaining prior events

In DreamBench-SWE’s preregistered successor audit, no external memory passed 21/180 cases; deterministic event memory passed 82/180. Conditions covered 60 traps with three seeds. This does not establish superiority among memory-bearing methods.

Small enough to inspect.

The standard-library CLI reads a supplied ledger. It checks structure and prints active rules for review.

An excerpt match is a string check; approval is a recorded attestation, not an authenticated identity. The checker does not establish source truth or semantic support, automatically activate rules, change model weights, or enforce guidance in a host.

Designed to be revised.

A palinode is a poem that revises an earlier position. Here the name is a reminder that rules, too, are provisional. Corrigibility means keeping the decision open to correction: preserve the evidence, inspect the result, and let a person change course.
